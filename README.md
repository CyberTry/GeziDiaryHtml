# GeziDiaryHtml
一个使用热力图记录你每天写日记多少的日记本
玩法与设计：用热力图记录你的写作旅程
这个页面把写日记变成了一件充满成就感的事情。它的核心是用数据可视化来追踪写作习惯，就像GitHub记录代码提交一样。

核心操作逻辑：

选择日记仓库：第一次使用时，你需要选择一个本地文件夹来存放日记。

每日写作与自动保存：在左侧编辑器区域可以使用Markdown语法写日记，系统会自动保存，文件名格式为YYYY-MM-DD.md。

热力图反馈：顶部的日历热力图会根据你每天日记的文本量（非空白字符数） 来显示不同深浅的绿色方块。写的字越多，颜色越深，帮你直观地看到自己的写作规律和“摆烂日”。

交互与视觉风格：

沉浸式编辑：支持编辑/预览/分屏三种视图，写作时能即时看到Markdown渲染效果。

便捷导航：你可以点击热力图上的任意方块来跳转到对应日期的日记，也提供了前后日期切换按钮和“回到今天”的快捷键。

视觉风格：整体采用类似GitHub的简洁风格，并支持亮色/暗色模式切换，适合长时间写作。
